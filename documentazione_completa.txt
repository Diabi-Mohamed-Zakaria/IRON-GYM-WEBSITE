                                MODELLI DATABASE (DAO)

📊 TABELLE DATABASE:

🔧 USER-DAO.JS:
Classe per gestione operazioni database utenti

📋 METODI PRINCIPALI:
- getUserByUsername(username): Recupera utente per username
- getUserById(id): Recupera utente per ID
- getUser(username): Recupera credenziali per Passport
- createUser(): Crea nuovo utente con hash password
- getAllUsers(): Recupera tutti gli utenti
- getUsersByRole(role): Recupera utenti per ruolo
- searchUsers(query): Cerca utenti
- deleteUser(id): Elimina utente

🔧 CLASS-DAO.JS:
Classe per gestione operazioni database classi

📋 METODI PRINCIPALI:
- getAllClasses(): Recupera tutte le classi
- getClassById(id): Recupera classe per ID
- searchClasses(query): Cerca classi
- getClassesByTrainer(trainerId): Classi di un trainer
- createClass(classData): Crea nuova classe
- updateClass(id, classData): Aggiorna classe
- deleteClass(id): Elimina classe
- getClassAvailability(classId): Disponibilità posti

🔧 BOOKING-DAO.JS:
Classe per gestione operazioni database prenotazioni

📋 METODI PRINCIPALI:
- createBooking(userId, classId): Crea prenotazione
- getBookingsByUser(userId): Prenotazioni utente
- getBookingsByClass(classId): Prenotazioni classe
- deleteBooking(bookingId, userId): Cancella prenotazione
- hasUserBookedClass(userId, classId): Verifica prenotazione
- getAllBookings(): Tutte le prenotazioni
- countUserBookings(userId): Conta prenotazioni utente

🔧 MEMBERSHIP-DAO.JS:
Classe per gestione operazioni database membership

📋 METODI PRINCIPALI:
- getMembershipByUser(userId): Membership utente
- getMembershipPlans(): Piani disponibili
- createMembership(): Crea membership
- createPayment(): Crea pagamento
- upsertMembership(): Crea/aggiorna membership
- getPaymentsByUser(userId): Pagamenti utente
- updatePaymentStatus(): Aggiorna stato pagamento
- getMonthlyRevenue(): Revenue mensile

🔧 REVIEW-DAO.JS:
Classe per gestione operazioni database recensioni

📋 METODI PRINCIPALI:
- createReview(reviewData): Crea recensione
- getAllReviews(): Tutte le recensioni
- getReviewsByType(type): Recensioni per tipo
- getReviewsByTrainer(trainerId): Recensioni trainer
- getAverageRatingByTrainer(): Rating medio trainer
- getAverageGymRating(): Rating medio palestra
- hasUserReviewedTrainer(): Verifica recensione esistente
- deleteReview(): Elimina recensione

================================================================================
                                API REST ENDPOINTS
================================================================================

👥 API USERS (/api/users):
- GET /: Tutti gli utenti (admin)
- GET /role/:role: Utenti per ruolo (admin)
- GET /trainers: Tutti i trainers (pubblico)
- GET /:id: Dettaglio utente (admin)
- POST /: Crea utente (admin)
- GET /search: Cerca utenti (admin)
- DELETE /:id: Elimina utente (admin)

📅 API CLASSES (/api/classes):
- GET /: Elenco classi (pubblico)
- GET /trainer: Classi trainer corrente
- GET /:id: Dettaglio classe
- GET /search: Cerca classi
- GET /:id/availability: Disponibilità posti
- POST /: Crea classe (admin/trainer)
- PUT /:id: Aggiorna classe (admin/trainer)
- DELETE /:id: Elimina classe (admin)

🎫 API BOOKINGS (/api/bookings):
- POST /: Crea prenotazione (autenticato)
- GET /me: Mie prenotazioni
- GET /class/:classId: Prenotazioni classe (admin)
- GET /trainer/class/:classId: Prenotazioni classe trainer
- DELETE /:bookingId: Cancella prenotazione

💳 API MEMBERSHIPS (/api/memberships):
- GET /me: Membership corrente
- GET /plans: Piani disponibili
- GET /user/:userId: Membership utente
- POST /: Crea/aggiorna membership

💰 API PAYMENTS (/api/payments):
- GET /user/:userId: Pagamenti utente
- GET /my: Miei pagamenti
- PUT /:paymentId/status: Aggiorna stato (admin)
- GET /revenue/:year/:month: Revenue mensile (admin)
- GET /revenue: Revenue mese corrente (admin)
- POST /: Crea pagamento (admin)

⭐ API REVIEWS (/api/reviews):
- GET /: Tutte le recensioni
- GET /gym: Recensioni palestra
- GET /trainer/:id: Recensioni trainer
- GET /stats/gym: Statistiche rating palestra
- GET /stats/trainer/:id: Statistiche rating trainer
- POST /: Crea recensione
- DELETE /:id: Elimina recensione

================================================================================
                                DATABASE SCHEMA
================================================================================

📊 TABELLA USERS:
- id (INTEGER PRIMARY KEY)
- username (TEXT UNIQUE)
- hash (TEXT) - Password hashata
- salt (TEXT) - Salt per password
- role (TEXT) - admin/trainer/client
- nome (TEXT)
- cognome (TEXT)
- email (TEXT UNIQUE)
- gender (TEXT) - male/female
- created_at (DATETIME)

📊 TABELLA CLASSES:
- id (INTEGER PRIMARY KEY)
- name (TEXT)
- trainer_id (INTEGER) - FK users
- time (TEXT)
- capacity (INTEGER)
- day_of_week (TEXT)
- description (TEXT)
- created_at (DATETIME)

📊 TABELLA BOOKINGS:
- id (INTEGER PRIMARY KEY)
- user_id (INTEGER) - FK users
- class_id (INTEGER) - FK classes
- booking_date (DATETIME)
- UNIQUE(user_id, class_id)

📊 TABELLA REVIEWS:
- id (INTEGER PRIMARY KEY)
- user_id (INTEGER) - FK users
- trainer_id (INTEGER) - FK users (nullable)
- rating (INTEGER) - 1-5
- title (TEXT)
- comment (TEXT)
- review_type (TEXT) - gym/trainer
- created_at (DATETIME)

📊 TABELLA MEMBERSHIPS:
- id (INTEGER PRIMARY KEY)
- user_id (INTEGER UNIQUE) - FK users
- plan_type (TEXT) - basic/premium/elite
- billing_period (TEXT) - monthly/annual
- price (DECIMAL)
- status (TEXT) - active/expired/cancelled
- start_date (DATE)
- end_date (DATE)
- created_at (DATETIME)

📊 TABELLA PAYMENTS:
- id (INTEGER PRIMARY KEY)
- user_id (INTEGER) - FK users
- membership_id (INTEGER) - FK memberships
- amount (DECIMAL)
- payment_method (TEXT) - cash/card/bank_transfer
- payment_status (TEXT) - pending/completed/failed/refunded
- payment_date (DATETIME)
- due_date (DATE)
- notes (TEXT)
