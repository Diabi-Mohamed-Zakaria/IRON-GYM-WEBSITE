================================================================================
                                SISTEMA DI AUTENTICAZIONE
================================================================================

🔐 STRATEGIA AUTENTICAZIONE:
- Passport Local Strategy
- Password hashing con crypto.scrypt
- Salt random per ogni password
- Session-based authentication

👥 RUOLI UTENTE:
- admin: Amministratore completo
- trainer: Trainer palestra
- client: Cliente/membro

🔒 MIDDLEWARE AUTORIZZAZIONE:
- ensureAuthenticated: Utente loggato
- ensureAdmin: Solo admin
- ensureTrainer: Trainer o admin
- ensureClient: Solo clienti

📋 FLUSSO AUTENTICAZIONE:
1. Registrazione: Crea utente con password in chiaro e gender
2. Login: Verifica credenziali con Passport (confronto diretto)
3. Sessione: Salva ID utente in sessione
4. Autorizzazione: Verifica ruolo per accesso risorse
5. Profilo: Gestione dati personali e aggiornamento password
